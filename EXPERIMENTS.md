# Проверка разных разделений

`explore.py` несколько раз делит встроенный набор Wine с сохранением пропорций
классов. На каждой обучающей части подгоняются простая базовая модель и
логистическая регрессия с масштабированием. Результаты относятся к соответствующей
отложенной части данного разделения.

```bash
python -m pip install -r requirements.txt
python explore.py
python explore.py --seeds 3 9 15 --c 0.5
python -m unittest -v
```

Результат исходного запуска (`C=1.0`):

| Seed | Baseline accuracy | Logistic accuracy |
|---:|---:|---:|
| 7 | 0.3889 | 0.9722 |
| 21 | 0.3889 | 0.9444 |
| 42 | 0.3889 | 0.9722 |

На 36 проверочных объектах одна ошибка меняет accuracy примерно на 0.0278.
Измени список seed и сравни разброс. Затем попробуй другое `--c`, но не объявляй
лучший результат на этих же просмотренных разделениях независимой проверкой.
Исходный отчёт `reports/metrics.json` использует seed 42; повторное исследование
этого разделения не создаёт новый test. Для новой итоговой оценки заранее выдели
отдельную проверочную выборку или собери новые данные.

Скрипт не изменяет `reports/`, `example.json` и сохранённую модель.
